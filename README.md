# Northstar Finds

A responsive static affiliate-marketing website starter. It can be uploaded directly to a GitHub repository and published with GitHub Pages.

## Customize before publishing

1. Replace **Northstar Finds** with your brand name in `index.html`.
2. Change every `https://example.com` link to an approved affiliate link.
3. Update `hello@example.com` with a real contact address.
4. Connect the email form in `script.js` to your newsletter provider (for example, Mailchimp, ConvertKit, or Buttondown).
5. Keep the affiliate disclosure and add a privacy policy page before applying to affiliate programs.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload these files to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** and choose `main` and `/ (root)`.
4. Save. GitHub will provide the public site address within a few minutes.

No build step is required.
